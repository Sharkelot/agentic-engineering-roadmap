# Eight-week curriculum roadmap

A self-study sequence using the repository's deterministic evaluation package and fictional support cases only.

1. [Python and API clients](lessons/week-01-python-sdk.md) — Python 3.12, async boundaries, local run artifacts.
2. [Schemas and data contracts](lessons/week-02-schemas-data.md) — Pydantic, JSONL validation, explicit contracts.
3. [Evaluation design](lessons/week-03-evaluation-design.md) — objectives, datasets, graders, human judgment.
4. [Metrics and regression](lessons/week-04-metrics-regression.md) — scoring, F1, compatible comparisons.
5. [OpenTelemetry and observability](lessons/week-05-observability.md) — spans, diagnostic signals, data minimization.
6. [Orchestration and reliability](lessons/week-06-orchestration-reliability.md) — async lifecycle, timeouts, failures.
7. [Docker, Kubernetes, and CI](lessons/week-07-deployment-ci.md) — packaging and automation; deployment is optional.
8. [Capstone and technical storytelling](lessons/week-08-capstone.md) — reproducible narrative, evidence, and limitations.

Use the [glossary](study-guides/glossary.md), [evaluation checklist](study-guides/evaluation-checklist.md), and [answer hints](solutions/README.md). Try each week's work before viewing hints.

The default course is local and deterministic. No paid API, GPU, account, or secret is required. Use synthetic support cases only; never include employer, customer, internal, confidential, or private project data/code, employer names, or private portfolio links.
