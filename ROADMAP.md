# Eight-week roadmap

1. Repository foundations and reliable Python tooling
2. Agent loops, tool boundaries, and deterministic fixtures
3. Structured outputs and validation
4. Retrieval and citation-grounded answers
5. Safety, privacy, and adversarial testing
6. Evaluation datasets and regression metrics
7. Optional HTTP model adapter tested with a local mock
8. Capstone integration, review, and documentation

Every default run is local, deterministic, and free of paid API, GPU, or secret requirements. Use synthetic support-agent cases only; never include employer, customer, internal, confidential, or private project data/code.
